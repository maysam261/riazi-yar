## ✨ ویژگی‌های نسخه ۱۲.۰

### 🌙 حالت شب (جدید!)
- ☀️ **روشن** — برای روز
- 🌙 **تاریک** — برای شب و چشم‌راحت‌تر
- 🌓 **خودکار** — پیروی از تنظیمات سیستم گوشی
- 🎨 دکمه‌ی سریع تغییر تم در نوار بالا
- 💾 ذخیره‌ی خودکار انتخاب شما

### 🎯 پنج موضوع اصلی

| موضوع | محتوا |
|-------|-------|
| 📏 **محیط** | مربع، مستطیل، مثلث، دایره، متوازی‌الاضلاع، لوزی، چندضلعی، شکل L، خانه، ورزشی |
| 📐 **مساحت** | همان + ذوزنقه + شکل‌های ترکیبی L، T، U، خانه، ورزشی، ویلا+باغچه |
| 🧊 **حجم** | مکعب، مکعب مستطیل، یافتن ضلع از حجم |
| 🍰 **کسرها** | مفهوم، معادل، ساده‌کردن، مقایسه، جمع، تفریق، ضرب، تقسیم، عدد مخلوط |
| 🔢 **اعداد اعشاری** | مفهوم، مقایسه، چهار عمل، تبدیل، **روی محور اعداد** |

### 📐 شکل‌های ترکیبی پیشرفته (جدید!)
- 🟢 **آسان**: مربع + مستطیل
- 🟡 **متوسط**: + مثلث + متوازی‌الاضلاع + شکل T + شکل U
- 🔴 **سخت**: + دایره + نیم‌دایره + ذوزنقه + خانه با باغچه

### 📏 آموزش واحدهای اندازه‌گیری (جدید!)
- 🟦 **سانتی‌متر مربع یعنی چه؟** — با نمایش مربع‌های کوچک
- 🧊 **سانتی‌متر مکعب یعنی چه؟** — با نمایش مکعب‌های کوچک
- 📐 analogy مناسب برای هر شکل (مثلث، دایره، لوزی و...)

### 🎨 اثبات فرمول‌ها با انیمیشن (جدید!)
- 🔺 **مثلث** → نصف مستطیل
- ⚪ **دایره** → π برابر مربع شعاع
- ▱ **متوازی‌الاضلاع** → برش + جابجایی
- ◆ **لوزی** → ۴ مثلث کوچک
- ⏢ **ذوزنقه** → دو ذوزنقه = یک مستطیل

### 📐 اعشار روی محور (جدید!)
- نمایش ۰ تا ۱ با تقسیم به دهم‌ها
- جمع اعشار (پرش به راست)
- تفریق اعشار (پرش به چپ)
- یافتن عدد روی محور

### 📚 درسنامه‌های غنی (مناسب سن ۸+)
هر درس شامل:
- 📖 **۳ پاراگراف توضیح** ساده
- 🧪 **کارت واحد اندازه‌گیری** در ابتدای درس
- 🎨 **کارت اثبات فرمول** (برای شکل‌های غیرمستطیلی)
- 📌 **۲ تا ۴ مثال حل‌شده**
- 💡 **نکات مهم**
- ⚠️ **اشتباهات رایج**

### 🎬 انیمیشن‌های تعاملی با کلیک
- کلیک روی شکل → پخش انیمیشن
- متن راهنما متناسب با درس: **«برای دیدن محیط/مساحت/حجم/کسر/اعشار، روی شکل بزن»**
- هر کلیک = پخش دوباره

### 🎯 سوالات چهارگزینه‌ای هوشمند

  - ✅ درست: `۴ × ضلع`
  - ❌ دیگر: مساحت، نصف، دو برابر

### ⚠️ نمره منفی در آزمون

## 🎨 نمونه‌ی سوالات

### 📏 محیط مربع
```
قاب عکس مربعی به ضلع ۵ سانتی‌متر.
برای قاب‌گیری دور آن چقدر چوب لازم است؟

پاسخ: ۲۰ سانتی‌متر
```

### 📐 مساحت شکل L
```
این شکل از دو مستطیل ساخته شده:
- مستطیل بزرگ: ۵ × ۳
- مستطیل کوچک: ۲ × ۴

مساحت کل = ۱۵ + ۸ = ۲۳ سانتی‌متر مربع
```

### 🍰 جمع کسر
```
۱/۲ + ۱/۳ = ?

گزینه‌ها:
الف) ۲/۵   ❌ (جمع صورت و مخرج)
ب) ۵/۶   ✅ درست
ج) ۲/۶   ❌ (فقط یکی)
د) ۱/۶   ❌

گام‌به‌گام:
- مخرج مشترک: ۶
- ۱/۲ = ۳/۶
- ۱/۳ = ۲/۶
- ۳ + ۲ = ۵
- نتیجه: ۵/۶
```

### 🔢 اعشار روی محور
```
نشانگر روی محور چه عددی را نشان می‌دهد؟
[محور ۰ تا ۱ با نشانگر روی ۰٫۳]

پاسخ: ۰٫۳
```

## 🔧 توسعه‌ی محلی

### اجرا
```bash
# Python
python -m http.server 8000

# Node.js
npx serve

# PHP
php -S localhost:8000
```
سپس باز کن: `http://localhost:8000`

> ⚠️ برای فعال شدن Service Worker، از HTTPS یا localhost استفاده کن.

### افزودن موضوع جدید
۱. تابع تولید سوال در `Generators` بنویس.
۲. در `LESSONS` درسنامه بنویس.
۳. در `bottomNav()` آیتم اضافه کن.
۴. در `defaultState.students[].progress` کلید جدید.

### افزودن انیمیشن جدید
۱. تابع در `ShapesAnim` بنویس با کلاس‌های `anim-*-loop`.
۲. از `wrapAnim(html, { hint })` استفاده کن.
