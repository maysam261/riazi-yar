## 🎨 نمونه‌ی سوالات

### 📏 محیط
```
قاب عکس مربعی به ضلع ۵ سانتی‌متر داریم.
برای قاب‌گیری دور آن چقدر چوب لازم است؟

[شکل مربع با برچسب ۵ روی ضلع]

پاسخ: ۲۰ سانتی‌متر
```

### 📐 مساحت (شکل ترکیبی)
```
نقشه یک خانه به شکل زیر (مستطیل + سقف مثلثی).
مساحت کل چقدر است؟

[شکل خانه با خط چین ارتفاع مثلث]

پاسخ: ۱۶ متر مربع
```

### 🧊 حجم
```
یک مکعب داریم که هر ضلعش ۳ سانتی‌متر است.
حجمش چقدر است؟

[شکل مکعب سه‌بعدی]

پاسخ: ۲۷ سانتی‌متر مکعب
```

### 🍰 کسر (چهارگزینه‌ای با گزینه‌های هوشمند)
```
حاصل جمع این دو کسر چقدر است؟
   ┌───┐   ┌───┐
   │ ۱ │   │ ۱ │
   ├───┤ + ├───┤ = ?
   │ ۲ │   │ ۳ │
   └───┘   └───┘

گزینه‌ها:
  الف) سه‌پنجم  (اشتباه: جمع صورت‌ها و مخرج‌ها)
  ب) پنج‌ششم  ✅ (درست)
  ج) دو‌ششم   (اشتباه: فقط یکی)
  د) یک‌ششم   (اشتباه کامل)

گام‌به‌گام:
- مخرج مشترک: ۶
- یک‌دوم = سه‌ششم
- یک‌سوم = دو‌ششم
- ۳ + ۲ = ۵
- پاسخ: پنج‌ششم
```

### 🔢 اعشار
```
حاصل جمع زیر را محاسبه کنید:
   ۳٫۴ + ۲٫۱ = ?

پاسخ: ۵٫۵
```

## 🔧 توسعه‌ی محلی

### اجرای محلی

```bash
# روش ۱: Python
python -m http.server 8000

# روش ۲: Node.js
npx serve

# روش ۳: PHP
php -S localhost:8000
```

سپس باز کن: `http://localhost:8000`

> ⚠️ **نکته:** برای فعال شدن Service Worker، باید از **HTTPS** یا **localhost** استفاده کنی.

### افزودن موضوع جدید

۱. تابع تولیدکننده‌ی سوال در بخش مربوطه بنویس (مثل `genNewTopic`).
۲. در `Generators` به مخزن اضافه کن.
۳. در `LESSONS` درسنامه بنویس.
۴. در `bottomNav()` آیتم جدید اضافه کن.
۵. در `defaultState.students[].progress` کلید جدید اضافه کن.

### افزودن انیمیشن جدید

۱. تابع در `ShapesAnim` بنویس با کلاس‌های `anim-*-loop`.
۲. از `wrapAnim(html)` در درسنامه استفاده کن.
۳. اگر انیمیشن ندارد، به‌جای `wrapAnim` مستقیم HTML بگذار.
