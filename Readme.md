## 🔧 توسعه‌ی محلی

### اجرای محلی

```bash
# روش ۱: Python
python -m http.server 8000

# روش ۲: Node.js
npx serve

# روش ۳: PHP
php -S localhost:8000
```

سپس باز کن: http://localhost:8000

⚠️ نکته: برای فعال شدن Service Worker، باید از HTTPS یا localhost استفاده کنی.

افزودن موضوع جدید

۱. تابع تولیدکننده‌ی سوال در بخش مربوطه بنویس (مثل genNewTopic).
۲. در Generators به مخزن اضافه کن.
۳. در LESSONS درسنامه بنویس.
۴. در bottomNav() آیتم جدید اضافه کن.

افزودن زمینه‌ی جدید به مسائل کلامی

در CTX_P یا CTX_A یک آبجکت جدید اضافه کن:

```javascript
{ 
  story: 'باغ گل به شکل', 
  u: 'متر', 
  ask: 'برای نرده‌کشی دور آن چقدر نرده لازم است؟' 
}
```
