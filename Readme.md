## ✨ ویژگی‌های نسخه ۱۳.۰

### 🎬 انیمیشن‌های جدید (۴ مرحله‌ای)
- **مرحله ۱**: کل سطح شکل با پالس ملایم
- **مرحله ۲**: کشیدن ضلع/قاعده
- **مرحله ۳**: خط چین ارتفاع + علامت زاویه ۹۰°
- **مرحله ۴**: نمایش فرمول نتیجه

برای همه‌ی شکل‌های مساحت: مربع، مستطیل، مثلث، دایره، متوازی‌الاضلاع، لوزی، ذوزنقه

### 🟦 انیمیشن تقسیم به مربع‌های واحد
- برای مربع و مستطیل: مربع‌های ۱×۱ یکی‌یکی «پاپ» می‌کنند
- دانش‌آموز تعداد مربع‌های واحد را می‌شمارد

### 🎬 انیمیشن محیط همه‌ی شکل‌ها
- چندضلعی منتظم: خط دور ضلع‌به‌ضلع
- متوازی‌الاضلاع، لوزی، ذوزنقه
- دایره: خط دور (نه شعاع)

### 🎨 الگوی سه‌رنگی
- 🟦 **سطح داخلی** (مساحت) — آبی-بنفش
- 🟧 **محیط** (خط دور) — نارنجی تیره
- 🟪 **اندازه‌گیری** (ارتفاع، قطر) — بنفش خط‌چین
- 🟨 **زاویه ۹۰°** — زرد

### 🆕 ویژگی‌های جدید
- 🌅 **چالش روزانه** با پاداش دوبرابر
- 💡 **راهنمای تدریجی** بعد از ۲ پاسخ غلط
- 🔊 **خواندن صوتی سوال** (اختیاری)
- ⏱ **حالت بدون تایمر** برای کاهش استرس
- 📤 **اشتراک کارنامه تصویری** (PNG)
- 🔧 **حالت Debug** برای توسعه‌دهنده
- 📋 **چک‌لیست بصری** در هر درسنامه
- 🎯 **پیام‌های تشویقی متنوع** (۱۵+ پیام)

### 🐛 رفع باگ
- ✅ برچسب نوار کسر معادل در SVG درست نمایش داده می‌شود
- ✅ برچسب محور اعشار با ممیز فارسی (٫) و رُند درست
- ✅ لوگوهای پیام‌رسان با قاب سفید کامل دیده می‌شوند

### 🌙 حالت شب (حفظ شده)
- ☀️ روشن
- 🌙 تاریک
- 🌓 خودکار

### 🎯 پنج موضوع اصلی
| موضوع | محتوا |
|-------|-------|
| 📏 **محیط** | مربع، مستطیل، مثلث، دایره، متوازی، لوزی، ذوزنقه، چندضلعی |
| 📐 **مساحت** | + ذوزنقه + L، T، U، خانه، ورزشی، ویلا |
| 🧊 **حجم** | مکعب، مکعب مستطیل |
| 🍰 **کسرها** | مفهوم، معادل، ساده، مقایسه، ۴ عمل، مخلوط، اعداد > ۱ |
| 🔢 **اعشار** | مفهوم، مقایسه، ۴ عمل، تبدیل، روی محور |

### 📊 مقایسه‌ی بصری
- **کسرها**: نوار کنار هم برای مقایسه
- **اعشار**: نوارهای هم‌مقیاس
